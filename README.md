## Featured Projects

### Demand Forecasting & Inventory Optimization

A demand forecasting and replenishment pipeline that combines daily forecasts, stock policies, campaign effects, ABC classification and inventory simulation for products and stores. This project was developed for a forecasting and inventory optimization hackathon and was the winning project.

**Technologies:** Python · pandas · NumPy · pytest  
[Repository](https://github.com/DPFNeiland/demand-forecasting-inventory-optimization)

### ProjetoVideoEdit — AI Video Post-Production Pipeline

An AI-assisted pipeline for transcription, automatic cuts, subtitles, short-video curation and final packaging. The project was designed as a modular workflow for audio-first content and uses configurable glossaries, markers and language-model providers.

**Technologies:** Python · FFmpeg · FFprobe · faster-whisper · Ollama · Groq API · Gemini API  
[Repository](https://github.com/Noxzxz/ProjetoVideoEdit)

### Spring Data Platform Course

An online course subscription platform with gamification, role-based access and domain modeling for courses, modules, lessons and enrollments. The backend follows a layered structure with REST endpoints, persistence and business rules for course access and progression.

**Technologies:** Java · Spring Boot · Spring Web · Spring Data JPA · PostgreSQL · H2 · Swagger/OpenAPI · Maven  
[Repository](https://github.com/Noxzxz/projeto-spring-data-platform-course)

### K-Means, SOM & Hybrid Clustering Analysis

A clustering study of a real-estate dataset using K-Means, Self-Organizing Maps and a hybrid SOM plus K-Means approach. The project includes dimensionality reduction, cluster visualization, cluster profiles and component analysis.

**Technologies:** Python · K-Means · Self-Organizing Maps · PCA  
[Repository](https://github.com/Noxzxz/TesteK-means)

### Air Quality Monitoring System

A monitoring system with dashboards, heatmaps, alerts, KPIs and charts supported by a REST API, a MySQL database and a sensor-data scraper. The project also includes data modeling and manual alert management through the application interface.

**Technologies:** JavaScript · Node.js · EJS · Python · MySQL · REST API  
[Repository](https://github.com/tech-espm/inter-3sem-2026-manalistas-panauaras)
